# Privacy

OTER_Y Home does not request Internet access and contains no analytics, advertising SDK, account system, or remote server integration.

Optional notification-listener access is processed on the device and is used only to:

- show current media title, artist, source and playback state;
- show whether a configured app currently has a notification.

The launcher stores tile labels, package names and the last active tile in Android `SharedPreferences` on the device. Uninstalling the app removes these settings.
