# OTER_Y Home 0.5

Galaxy Z Fold8의 커버 화면과 내부 화면에 맞춰 제작한 개인용 안드로이드 홈 런처입니다. 제공된 M.P.C 화면을 참고하되 원본 코드·APK·그래픽 자산은 사용하지 않고 독립적으로 구현했습니다.

## 구현된 기능

- 폴드8 커버/내부 화면 폭을 자동 감지하는 두 가지 레이아웃
- Fold8 실제 비율 기준: 내부 1828×2448, 커버 1248×1972
- 셀룰러·Wi-Fi 연결 상태와 실제 배터리 잔량을 표시하는 전용 상태 영역
- 크림 배경, 먹색 타일, 오렌지·노란색 상태점
- 실제 한 달을 7열 점으로 표시하고 오늘을 오렌지색으로 강조하는 달력
- 실제 미디어 볼륨과 연결된 세로형 페이더, 탭 음소거/복원
- 페이더를 위로 끝까지 당기면 Spotify, 아래로 끝까지 당기면 카메라 실행
- 재생/일시정지 버튼, 독립된 첫 줄의 회색 곡 제목, 둘째 줄에서 위아래로 움직이는 검은 세로 파형
- 곡 정보·파형·대형 타이포그래피는 실제 재생 중에만 표시
- 재생 중 이동하는 대형 타이포그래피와 진입·잠금 해제 시 순차 애니메이션
- 패드를 아래로 당겨 보조 앱 실행, 노란 점으로 보조 앱 설정 표시
- 알림이 있는 앱 패드 전체를 오렌지색으로 표시
- Media/Work 노브 회전 후 해당 폴더 열기
- 타일을 길게 눌러 기본 앱·보조 앱·위치를 설정
- 위로 쓸어 전체 앱 열기, 아래로 쓸어 홈 복귀
- 앱 서랍 진입 시 시트 상승, 아이콘 순차 상승, 원형 인디케이터 회전
- 좌우 스와이프로 홈 모듈 페이지와 회전 디스크 기반 미디어 페이지 전환
- 펼침/접힘 또는 화면 크기 변경 시 즉시 재배치

## 설치 및 첫 설정

1. 빌드 결과인 `app-debug.apk`를 폴드8로 옮겨 설치합니다.
2. 출처를 확인할 수 없는 앱 설치를 묻는 경우, APK를 연 파일 앱에 대해서만 일시 허용합니다.
3. 앱을 열고 기본 홈 앱 선택 화면에서 **OTER_Y Home**을 선택합니다.
4. 곡 정보와 알림 표시를 사용하려면 안내에 따라 **알림 접근**에서 OTER_Y Home을 허용합니다.
5. 타일을 길게 눌러 각 칸에 사용할 앱을 지정합니다.

## 조작법

- 앱 타일 터치: 앱 실행
- 앱 패드 아래로 당기기: 노란 점에 연결된 보조 앱 실행
- 앱 타일 길게 누르기: 기본·보조 앱 변경 또는 위치 바꾸기
- 원형 Media/Work 노브 터치: 분류 폴더 열기
- 볼륨 페이더 드래그: 미디어 볼륨 조절
- 볼륨 페이더 탭: 음소거/이전 음량 복원
- 페이더 위/아래 끝단: Spotify/카메라 실행
- 우측 상단 재생 버튼: 현재 미디어 재생/일시정지
- 홈에서 위로 쓸기: 전체 앱
- 홈에서 좌우로 쓸기: 기본 페이지/미디어 페이지 전환
- 전체 앱에서 아래로 쓸기: 홈

## 권한과 개인정보

런처는 인터넷 권한을 요청하지 않으며 데이터 전송 코드를 포함하지 않습니다. 알림 접근 권한은 현재 재생 중인 곡과 앱별 알림 유무를 기기 안에서 읽는 용도로만 사용합니다. 볼륨 조절은 안드로이드의 미디어 볼륨 기능을 사용합니다.

## 소스 빌드

Android Studio에서 이 폴더를 연 뒤 JDK 17과 Android SDK 35를 설치하고 `assembleDebug`를 실행합니다. 결과물은 `app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다.

이 프로젝트는 개인 사용을 전제로 합니다. M.P.C 명칭·로고 또는 제작자의 배포 파일을 포함하지 않으며, 동일한 이름으로 공개 배포하지 않는 것을 권장합니다.
